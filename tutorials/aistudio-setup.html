Google AI Studio Setup

Game Bot Creator's LLM-assisted scenario/screen generation needs a Gemini API key. This is where to get one, free, in about two minutes.

You only need this once. One key works across every config you use LLM-assisted generation on — paste it into the Settings tab's AI Generation group and it's done.
1

Open Google AI Studio

Go to aistudio.google.com and click Get started in the top-right corner.

2

Sign in with a Google account

Pick an existing Google account, or click Create account right there if you don't have one yet — a personal Gmail account works fine. Either path lands you in the same place.

3

Open the API Keys page

You'll land on AI Studio's Build screen. In the bottom-left toolbar, click the key icon.

4

Copy your key

AI Studio has already provisioned one API key for this account — no extra click needed. Copy it and treat it like a password: anyone who has it can spend your quota.

good to know Free-tier daily request limits are applied per Google Cloud project, not per individual API key — a second key under the same project shares one quota, it doesn't add more of it.

5

Or create a separate key optional

Want a dedicated key instead of reusing the default — say, to revoke it independently later? Click Create API key, name it, choose a project, and confirm.

Back in Game Bot Creator

Paste the key into the Settings tab's AI Generation group, set Provider to Google, and the "AI Generate…" buttons in the Scenario and Scene Editors light up.
